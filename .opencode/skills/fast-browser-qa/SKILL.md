## What I do

I spin up a browser session to physically interact with the application and verify my code works.

## When to use me

Use this immediately after writing any frontend code or modifying a user-facing workflow.

## Instructions for the Agent

Leverage your high-throughput speed to act as an automated QA engineer:

1. After updating a frontend component, automatically launch a browser testing tool.
2. Click through the UI flow exactly as a user would.
3. Capture the console logs and check for hydration errors or silent failures.
4. If an error is found, use your `<think>` tags to analyze the stack trace, fix the code, and re-test until the console is clean.
